Commands and admin tools ​

Players mostly use the tablet and NPCs; admins do nearly everything from /adminps. Admin commands accept anyone with the command ace or a framework group listed in Config.AdminGroups (default admin, superadmin).

Player commands ​

CommandWhat it does
/pilottabletOpen the pilot tablet
/myflightsList your recorded flights
/resetpilothudReset the HUD layout
/unstuckjobsClear a stuck job state
/groundservicesIn an aircraft: request ground services. On foot: open the crew board (sign on there)
/gscrewOpen the ground-crew board from anywhere
/msefleetGround-vehicle menu
/apheading <deg> · /apalt <ft> · /apmode nav|hdgAutopilot heading, altitude and mode
/heavylift · /heavyliftcancelStart or cancel a heavy-lift job
/cancelmedevacCancel a medevac
/subco ...Sub-company actions: create, rename, disband, assign, unassign, fleet, board

Keys ​

Players can rebind these in Settings → Key Bindings → FiveM.

KeyAction
F10ATC menu and cursor (/atccursor if F10 is taken)
EInteract with NPCs and the ground board; sit at the tower console (that one is rebindable as "ATC console: sit at the screens")
BSmoke colour (sky writing, airshow)
P / G / O / HAirshow leader: cycle routine, engage, start, disengage
LBelt loader on/off
YDrop cargo (smuggling; set by Config.Smuggling.dropKey)
(unbound)Autopilot and autoland toggles — bind them yourself

Admin commands ​

CommandWhat it does
/adminpsAdmin panel (name set by Config.AdminCommand)
/atcscope place|list|remove|calibratePlace and manage ATC tower consoles
/gsboard place|list|removePlace and manage ground-service boards
/airportnavShow an airport's taxiway network; editing and saving it is admin-only
/aitraffic preset light|medium|heavy · why · hereTune and diagnose AI traffic (ace msflightsim.admin)
subcodiag (server console)Check the sub-company database setup

The admin panel ​

/adminps has these tabs:

TabFor
PlayersGive or revoke licences, reset strikes, blacklist, whitelist pilots
ZonesCreate and edit altitude and no-fly zones
LocationsEnable or disable NPC sites
AirportsAdd airports or override built-in ones. A disabled airport has no jobs, ATC or AI. Capture Walk records points as you walk
ScreensATC consoles and ground-service boards
Licensed PilotsEvery pilot, online and offline
AircraftThe dealer list
JobsOn/off per mission
SalariesPay presets and the economy gauge
SettingsGeneral options
