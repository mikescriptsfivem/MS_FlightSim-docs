Integrations ​

All integrations are off or auto-detected by default. Their code sits in the open bridge/ folder so you can adapt them to custom scripts.

IntegrationSettingWhat it does
Your DMV / licence scriptConfig.DMVBridge.enabledAccept a licence from your own script in place of the in-game licence. Edit Framework.HasDMVLicense in bridge/server.lua to read it
City hallConfig.CityHallBridgePilots buy a physical licence card at city hall after training. With enabled = true and requirePhysicalLicense = true, missions also require the card
Company fundConfig.CompanyBridge.mode'internal' (default), 'society' (ESX esx_addonaccount — esx_billing invoices land in the fund), 'external' or 'disabled'
Discord logsconvar ms_flightsim_webhookSends the script's logs to a Discord channel
ATC voice re-recordingconvar ms_flightsim_elevenlabs_keyOnly needed to record your own ATC voice lines. The shipped voice works without it
Dispatchps-dispatchAuto-detected

Keep secrets in convars ​

Never put secrets in a config file

Put the webhook URL and API keys in server.cfg with set (not setr). config.lua and config_overrides.lua are sent to every player's game, so anything in them can be read.

cfg
set ms_flightsim_webhook "https://discord.com/api/webhooks/..."
set ms_flightsim_elevenlabs_key "your-key"   # only if you re-record ATC voice

Exports for developers ​

Other resources can call MS_FlightSim through exports. Server-side examples:

lua
local MSF = exports['MS_FlightSim']

MSF:HasCertificateSync(identifier, 'plane')   -- 'plane' | 'heli' | a specialist rating
MSF:GetPilotRankScore(identifier)
MSF:IsATCOnDuty()
MSF:HasPhysicalLicense(identifier, licenseType)   -- for police scripts checking a licence card
MSF:GetServerWind()
MSF:RaiseGroundRequest(spec)
MSF:GroundCrewCount()

Client-side: HUD_AddWarning, HUD_RemoveWarning, GetTCASContacts, IsTCASFailed.
